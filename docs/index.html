The server only ever reports busy blocks for a day, never an explicit "free" marker. A day is flagged as a possible opening here if it has no reported busy blocks at all, or has a gap of 15+ minutes between two busy blocks. Always double-check on the booking page before assuming a slot is truly bookable. Dates beyond each doctor's "last published" date simply have no schedule in the system yet.
